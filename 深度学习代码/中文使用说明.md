# 线宽预测深度学习使用说明

## 1. 前期准备

你需要整理一个 CSV 表格，每一行代表一次实验打印结果。

推荐第一轮先使用每张图片的平均线宽或中位数线宽作为因变量，不要一开始把同一张图片的 10 个测量点都当成完全独立实验。因为这 10 个点对应的打印参数完全相同，本质上更像同一次实验中的重复测量。

CSV 表头必须是：

```csv
arm_speed,extrusion_speed,nozzle_height,alginate_concentration,nozzle_diameter,line_width
```

含义如下：

- `arm_speed`：机械臂运动速度
- `extrusion_speed`：喷头挤出速度
- `nozzle_height`：喷头工作高度
- `alginate_concentration`：海藻酸钠浓度
- `nozzle_diameter`：喷头直径
- `line_width`：测得线宽，建议单位统一为 mm

## 2. 数据量建议

第一轮可以先用较少数据跑通流程：

- 6-10 组：只能测试代码流程，模型分数不可靠
- 20-30 组：可以初步观察趋势
- 50 组以上：模型评估开始更有参考价值
- 100 组以上：更适合训练神经网络

如果数据很少，传统机器学习例如线性回归、随机森林、XGBoost 往往比深度学习更稳。你这次想顺带学习深度学习，可以先用小型神经网络跑通，然后逐步增加数据。

## 3. 运行训练

先把真实实验数据保存成 CSV。可以参考：

```text
outputs/line_width_training_template.csv
```

然后打开：

```text
outputs/train_line_width_model.py
```

把顶部这一行改成你的真实 CSV 路径：

```python
DATA_PATH = Path(__file__).resolve().parent / "line_width_training_template.csv"
```

在 VS Code 中右键选择 `Run Python File in Terminal`。

## 4. 训练后输出

训练完成后会生成文件夹：

```text
outputs/line_width_model_output
```

里面主要有：

- `line_width_model.pt`：训练好的神经网络模型
- `x_scaler.joblib`：输入参数标准化器
- `y_scaler.joblib`：线宽标准化器
- `test_predictions.csv`：测试集真实值和预测值对比
- `metrics.json`：MAE、RMSE、R2 指标
- `training_curve.png`：训练损失曲线
- `prediction_check.png`：真实线宽与预测线宽对比图

## 5. 指标怎么看

- MAE：平均绝对误差，越小越好。例如 MAE=0.05 mm，表示平均预测误差约 0.05 mm。
- RMSE：对大误差更敏感，越小越好。
- R2：越接近 1 越好；数据很少时 R2 可能很不稳定，甚至为负。

第一轮小数据训练时，不要只看 R2。更应该看：

- 预测误差是否在实验可接受范围内
- 训练曲线是否明显下降
- 增加数据后测试误差是否变小

## 6. 用模型预测新参数

训练完成后打开：

```text
outputs/predict_line_width.py
```

修改：

```python
NEW_SAMPLE = {
    "arm_speed": 10.0,
    "extrusion_speed": 1.2,
    "nozzle_height": 0.8,
    "alginate_concentration": 2.0,
    "nozzle_diameter": 0.41,
}
```

然后运行这个文件，就会输出预测线宽。

## 7. 后续继续训练

如果第一轮效果一般，建议不是简单增加训练轮数，而是优先增加实验数据。

推荐流程：

1. 先训练第一轮模型。
2. 查看误差较大的实验条件。
3. 在这些参数附近补充实验。
4. 把新数据追加到 CSV。
5. 重新运行 `train_line_width_model.py`。

这样比只把同一批数据反复训练更多轮更有效。

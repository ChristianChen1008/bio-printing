## 如何查看更详细历史

查看全部提交：

```bash
git log --oneline
```

查看某次提交具体改了什么：

```bash
git show <提交号>
```

查看某个文件的历史：

```bash
git log --oneline -- "控制代码/PathProgram.py"
```

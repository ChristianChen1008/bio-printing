# 自动化指令

## 更新日志与 GitHub 同步

默认 GitHub 远端仓库：`https://github.com/ChristianChen1008/bio-printing`

请执行一次项目同步流程：先检查当前文件夹的 Git 状态和今天新增/修改的真实文件，排除 `~$` 开头的 Office 临时锁文件、`__pycache__`、`.pytest_cache` 等缓存；把今天的重要更新按日期写入 `docs/更新日志.md`，内容包含新增文件、修改功能、数据/文档变化和验证结果；然后运行合适的测试或语法检查；确认通过后，只暂存本次真实更新相关文件，提交一个简洁中文 commit，并推送到 GitHub 远端同步。最后告诉我提交号、推送分支、验证结果，以及哪些临时文件没有上传。
